# Ink Design System

Preserve xuan paper, ink mountains, particle birds, cinnabar seals, restrained gold, translucent cloud navigation, and album-leaf article cards.

- Reuse `public/art/ink-scroll-hero-v1.png`; avoid generic technology stock imagery.
- Use existing ink, paper, cinnabar, and muted-gold CSS variables.
- Keep login visible and navigation translucent.
- Treat seals as small accents.
- Preserve contrast, keyboard focus, reduced-motion support, and responsive layout.
- Inspect desktop and mobile screenshots before reporting completion.
- Reject neon cyberpunk, generic SaaS gradients, excessive glass, and template-like bento layouts.
