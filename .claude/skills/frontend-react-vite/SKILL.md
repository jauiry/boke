# Frontend React Vite

1. Read the target component, callers, types, styles, and tests.
2. Prefer existing components, hooks, utilities, and dependencies.
3. Keep routing aligned with `src/App.tsx` and article data in `src/data/blogData.ts`.
4. Preserve lazy loading and avoid increasing the initial bundle without evidence.
5. Use semantic HTML, accessible labels, keyboard behavior, and visible focus.
6. Avoid `any`, duplicated state, unbounded effects, and listeners without cleanup.
7. Do not add dependencies without explicit approval.
8. Run lint, typecheck, production build, and relevant Playwright tests.
